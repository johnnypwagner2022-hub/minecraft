# PocketVoxel

A fast, original voxel sandbox inspired by the early/simple feel of Minecraft Pocket Edition.

## Current build

- First-person 3D voxel world
- Procedural terrain
- Grass, dirt, stone, sand, wood and leaves
- Trees
- Block breaking and placing
- WASD movement, mouse look and jump
- Touch controls for phones/tablets
- Hotbar with block selection
- Gravity and collision
- Day/night lighting
- Instanced rendering for low draw-call overhead
- No proprietary Minecraft code, textures, sounds, or assets

## Play

Open `index.html` in a browser, or enable GitHub Pages for the repository.

### Desktop

- WASD: move
- Mouse: look
- Space: jump
- Left click: break
- Right click: place
- 1-6: select block

### Mobile

Use the on-screen movement/look controls and action buttons.

## Roadmap

Chunk streaming, greedy meshing, caves, water, inventory, crafting, save/load, mobs, and more optimization will be added incrementally.
